# SoftNexis_SQL_Internship - Task_2

Department Salary Summaries, Yearly Hiring Trends, & Validation Queries in MySQL for SoftNexis Tech company

SQL App used: MySQL Workbench 8.0

Database used: employees_sample

Validation Queries Result: Total Current Active Employees = 240124, Null Department Assignments Count = 0

Note: 'Where' vs 'Having' keywords - 'Where' filters individual rows before they are grouped together, whereas 'Having' filters the summarized group results after 'Group by' has run. Aggregate & Window functions - used 'Count()', 'Avg()', 'Min()', 'Max()', & 'Lag()' along with 'Round()' & 'Format()' to build clean department salary summaries, yearly hiring trends, & salary distribution reports.
